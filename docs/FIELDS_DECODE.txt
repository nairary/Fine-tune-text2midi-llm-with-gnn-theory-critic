Ниже — компактная памятка по полям аккордов и связанным данным в датасете HookTheory (по твоим CSV + структуре JSON/XML). Это удобная «легенда» для чтения и парсинга.

---

# 1. Общая структура трека

Основные разделы внутри записи:

* `meta` / верхние поля — метаданные трека
* `json` — структурированное представление музыки
* `xmlData` — исходная theorytab-разметка
* `json.chords` — аккорды
* `json.notes` — мелодия

---

# 2. Метаданные трека

| поле               | значение                  |
| ------------------ | ------------------------- |
| `artist`           | исполнитель               |
| `title`            | название                  |
| `key`              | тональность (тоника)      |
| `mode`             | режим (числовой код лада) |
| `BPM`              | темп                      |
| `beats_in_measure` | размер такта              |
| `YouTubeID`        | ID видео                  |
| `duration`         | длительность сегмента     |
| `global_start`     | начало сегмента в аудио   |
| `active_start`     | начало активной части     |
| `active_stop`      | конец активной части      |

---

# 3. Структура аккорда (`json.chords`)

Каждый аккорд — объект:

```text
root
type
inversion
applied
borrowed
adds
alterations
suspensions
omits
pedal
beat
duration
isRest
```

---

# 4. root — ступень аккорда

Ступень относительно текущей тональности.

| значение | смысл |
| -------- | ----- |
| 1        | I     |
| 2        | II    |
| 3        | III   |
| 4        | IV    |
| 5        | V     |
| 6        | VI    |
| 7        | VII   |
| 0        | пауза |

Пример:

```
root = 5
```

→ доминанта.

---

# 5. type — размер аккорда

Определяет количество терций.

| type | аккорд          |
| ---- | --------------- |
| 5    | трезвучие       |
| 7    | септаккорд      |
| 9    | нонаккорд       |
| 11   | ундецимаккорд   |
| 13   | терцдецимаккорд |

---

# 6. inversion — обращение

| значение | обращение    |
| -------- | ------------ |
| 0        | основной вид |
| 1        | первое       |
| 2        | второе       |
| 3        | третье       |

---

# 7. applied — secondary function

Указывает вторичную функцию.

| значение | значение       |
| -------- | -------------- |
| 0        | обычный аккорд |
| n        | аккорд V/n     |

Пример:

```
root = 5
applied = 5
```

→ **V/V**

---

# 8. borrowed — borrowed harmony

Используется для модальной смеси.

Возможные значения:

| значение           | смысл                |
| ------------------ | -------------------- |
| null               | обычная гармония     |
| `"major"`          | borrowed из мажора   |
| `"minor"`          | borrowed из минора   |
| `[0,2,4,5,7,9,11]` | явное описание шкалы |

Массив задаёт интервалы ступеней (в полутонах).

---

# 9. adds — добавленные ступени

Массив добавленных интервалов.

Примеры:

```
[9]
[4]
[6]
```

означает:

```
add9
add4
add6
```

---

# 10. suspensions — задержания

Массив:

| значение | смысл |
| -------- | ----- |
| 4        | sus4  |
| 2        | sus2  |

---

# 11. alterations — альтерации

Изменённые интервалы.

Примеры:

```
#5
b13
b9
```

---

# 12. omits — пропущенные ступени

Какие ноты убраны.

| значение | смысл |
| -------- | ----- |
| 3        | omit3 |
| 5        | omit5 |

---

# 13. pedal

Педальная нота.

Обычно `null`.

---

# 14. isRest

| значение | значение |
| -------- | -------- |
| true     | пауза    |
| false    | аккорд   |

---

# 15. позиционные поля

| поле               | значение                           |
| ------------------ | ---------------------------------- |
| `beat`             | позиция в долях                    |
| `duration`         | длительность в долях               |
| `recordingEndBeat` | конец аккорда (редко используется) |

---

# 16. пример аккорда

```json
{
  "root": 5,
  "type": 7,
  "inversion": 0,
  "applied": 5,
  "adds": [9],
  "suspensions": [4]
}
```

Расшифровка:

```
V7sus4add9/V
```

---

# 17. ноты (`json.notes`)

Каждая нота содержит:

| поле       | значение     |
| ---------- | ------------ |
| `sd`       | ступень      |
| `octave`   | октава       |
| `beat`     | начало       |
| `duration` | длительность |
| `isRest`   | пауза        |

Ноты записаны **относительно тональности**, а не абсолютными MIDI.

---

# 18. ключевые идеи кодировки

HookTheory описывает музыку как:

```
relative scale degree
+
functional harmony
+
chord extensions
```

а не как абсолютные ноты.

---

# 19. формула восстановления аккорда

Аккорд можно восстановить из:

```
root
type
inversion
applied
borrowed
adds
alterations
suspensions
omits
```

---

# 20. что ещё остаётся не полностью документировано

| поле               | комментарий                |
| ------------------ | -------------------------- |
| `mode`             | числовая кодировка лада    |
| `alternate`        | альтернативное имя аккорда |
| `pedal`            | редкие случаи              |
| `recordingEndBeat` | почти всегда null          |
